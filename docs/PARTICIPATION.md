# 기관 참여 절차 안내 (Institutional Participation)

한림 AI에듀테크 오픈소스 커뮤니티는 대학·공공기관·기업·협회 등이 **기관 명의로 참여**할 수 있습니다.

> 개인으로 기여하고 싶으시다면 이 문서가 아니라 [`CONTRIBUTING.md`](../CONTRIBUTING.md)를 보십시오. 별도 등록 없이 바로 Pull Request를 보내실 수 있습니다.

---

## 1. 먼저 한번 써보십시오

참여 여부를 결정하시기 전에 **설치해서 직접 써보시기를 권합니다.** 저장소를 내려받아 사용하시는 데에는 어떤 절차도 필요하지 않습니다.

```bash
git clone https://github.com/hallym-aiedu-center/ai_prof_lite.git
cd ai_prof_lite
./setup_en.sh
```

설치 과정에서 막히는 부분이나 개선이 필요한 점이 보이시면 **이슈로 알려주시는 것만으로도** 저희에게 큰 도움이 되고, 그것이 곧 커뮤니티 참여 활동이 됩니다.

> 설치에 GPU와 OpenAI API 키가 필요합니다. 환경 구성이 어려우시면 사무국으로 연락 주십시오. 원격으로 지원해 드립니다.

## 2. 참여하면 무엇이 좋은가요

| 혜택 | 내용 |
|---|---|
| 기술 확보 | 강의 자동 제작 파이프라인을 자체 개발 없이 기관 환경에 설치·활용 |
| 규격 참여 | 고등교육 AI 연동 규격 수립 과정에 기관 의견 반영 |
| 대외 표기 | 참여기관 명부 등재 및 커뮤니티 공식 자료에 기관명 표기 |
| 네트워크 | KELI 참여 대학 및 에듀테크 기업과의 기술 교류 |
| 인력 | 소속 학생·연구자의 실제 오픈소스 프로젝트 참여 기회 |

**비용은 없습니다.** 회비나 라이선스 비용을 부과하지 않습니다. (자체 인프라 구축·운영 비용과 외부 API 사용료는 기관 부담입니다.)

## 3. 참여 요건

아래 4가지를 모두 충족하면 참여기관으로 등록됩니다.

| # | 요건 | 확인 방법 |
|---|---|---|
| ① | 기관장 또는 위임받은 부서장 명의의 참여 의사 표시 | **참여확인서 1부** |
| ② | 커뮤니티 담당자 1명 이상 지정 | 신청서 기재 |
| ③ | 거버넌스 규정 및 행동 규범 준수 동의 | 신청서 체크 |
| ④ | 등록 후 6개월 이내 기여 활동 1건 이상 | 저장소 활동 기록 |

**별도의 협약서(MOU) 체결은 필요하지 않습니다.** 기관 내부 방침상 정식 협약이 필요하신 경우에만 별도 협의합니다.

## 4. 참여 절차

```
① 신청        ② 검토        ③ 승인        ④ 등재
   │             │             │             │
 신청 이슈     사무국 확인   운영위원회    MEMBERS.md
 또는 공문     (3영업일)    서면 의결     등재 + Org 초대
                            (2주 이내)
```

### ① 신청

편한 방법을 선택하십시오.

- **온라인** — [`🏛 기관 참여 신청` 이슈 템플릿](../../issues/new?template=institution-application.md)으로 등록
- **서면** — 참여확인서를 작성·날인하여 사무국 이메일로 회신

### ② 검토

사무국이 3영업일 이내에 요건 충족 여부를 확인하고 담당자에게 회신합니다.

### ③ 승인

운영위원회가 심의·의결합니다. 정기회의를 기다릴 필요 없이 서면 의결이 가능하며, 통상 2주 이내에 결과를 회신합니다.

### ④ 등재

- [`MEMBERS.md`](../MEMBERS.md)에 기관명이 등재됩니다. **Pull Request로 처리**되므로 등재 시점이 기록에 남습니다.
- 담당자가 GitHub 조직([hallym-aiedu-center](https://github.com/hallym-aiedu-center))에 초대됩니다.
- 참여기관 확인서를 발급받을 수 있습니다.

## 5. 참여 후 활동 방법

아래 유형 중 기관 여건에 맞는 것을 선택하십시오. **모든 유형이 동등한 참여 활동으로 인정됩니다.**

| 유형 | 활동 내용 | 필요 역량 | 부담 |
|---|---|---|---|
| **D. 활용·배포** | 기관 환경에 설치·시범 운영 후 결과 회신 | 시스템 운영 | **낮음** |
| **F. 이슈·검토** | 버그 제보, 기능 제안, 규격 초안 검토 의견 | 사용 경험 | **낮음** |
| **E. 거버넌스 참여** | 기술워킹그룹 참석, 위원 파견 | 담당자 지정 | **낮음** |
| **C. 문서·번역** | 가이드 작성, 다국어 번역, 사례집 집필 | 문서 작성 | 중간 |
| **B. 데이터·콘텐츠 기여** | 강의 템플릿, 프롬프트 세트, 평가 루브릭 제공 | 교육 기획 | 중간 |
| **A. 코드 기여** | 기능 구현, 버그 수정, 테스트 추가 | 개발 인력 | 높음 |

**처음 참여하시는 기관께 권하는 경로** — D(시범 설치) → F(사용 후 의견 제출) → E(워킹그룹 참석). 개발 역량 없이도 충분히 참여하실 수 있으며, 실제로 규격 수립에는 현장 담당자의 사용 경험이 더 중요합니다.

## 6. 활동 기록과 확인서 발급

- 모든 활동은 저장소의 이슈·Pull Request·회의록에 자동으로 기록됩니다.
- 기관에서 실적 증명이 필요한 경우 사무국에 요청하시면 **활동확인서**를 발급해 드립니다.

## 7. 자주 묻는 질문

**Q. 개발 인력이 없어도 참여할 수 있나요?**
가능합니다. D·E·F 유형은 개발 역량 없이 수행할 수 있습니다.

**Q. 협약식이나 행사에 참석해야 하나요?**
아닙니다. 참여확인서 회신으로 절차가 끝납니다.

**Q. 우리가 만든 자료를 공개하면 저작권은 어떻게 되나요?**
저작권은 기여 기관에 그대로 남습니다. 커뮤니티 라이선스(코드 Apache-2.0, 문서 CC BY 4.0)에 따라 타인의 이용을 허락하는 것이며, 기관명은 항상 표기됩니다.

**Q. 참여 후 탈퇴할 수 있나요?**
가능합니다. 서면 요청으로 탈퇴하실 수 있으며, 이미 기여한 산출물은 라이선스에 따라 저장소에 남습니다.

**Q. 해외 기관도 참여할 수 있나요?**
가능합니다. UI와 문서가 한국어·English·日本語·中文으로 제공됩니다.
